# infra-learning

ネットワーク、インフラ、セキュリティ、AI自動化を横断できるエンジニアを目指す学習記録です。
実機と仮想環境で手を動かし、学んだことと成果物をここに残します。

## 構成

| 場所 | 内容 |
| --- | --- |
| [docs/setup-log.md](docs/setup-log.md) | 学習環境の構築メモ |
| [notes/](notes/) | 週ごとの学習メモ |

成果物やラボの設定は、作り始めた時点でフォルダを追加します。

## 学習環境

- Windows 10 Pro 22H2（ESU登録）
- WSL2 + Ubuntu
- Wireshark
- Cisco Packet Tracer

## このリポジトリのルール

公開リポジトリなので、次のものは置きません。

- 職場の設定ファイル、ログ、資料
- パケットキャプチャ（`.pcap`、`.pcapng`）の生データ。必要なら要点だけを文章や画面の切り抜きで残す
- パスワード、APIキー、秘密鍵などの認証情報
- 自宅の実IPアドレス、Wi-FiのSSID、MACアドレスなど、環境を特定できる情報
